# Tool Schema Bias for Agentic Environment
Date: Sep 29, 2026 | Author: Yinhong Liu



Using LLM for agentic tool-use tasks are ubiqutious today. But the design of tool schema doesn't usually treated the job for Training-side, but more as Environment-side. 
Very intuitively, we can see there is definitely not single way to define a tool schema, as schema is just one interface representation to invoke an action in environment. For the same invokation, we can design arbitrary interface as we want.
